# 📰 Sabar Kotha (সবার কথা)

> A modern, full-stack Bengali news and live-streaming platform featuring interactive **2.5D Parallax Animations**.

[![Live App](https://img.shields.io/badge/Live_Demo-sabarkotha.vercel.app-brightgreen?style=for-the-badge&logo=vercel)](https://sabarkotha.vercel.app/)
[![GitHub Repo](https://img.shields.io/badge/GitHub-Repository-blue?style=for-the-badge&logo=github)](https://github.com/sayanshin/sabarkotha)

---

## 🌟 Key Features

* 🎭 **2.5D Parallax Visuals:** Multi-layered visual depth designed for modern digital storytelling.
* 📡 **Live Stream Hub:** Embedded YouTube live broadcast section with custom overlay and controls.
* 📰 **Dynamic Content Modules:** Categorized sections for news updates, story episodes, and e-paper listings.
* 🛡️ **Admin Panel:** Secure authentication and token storage for real-time dashboard updates.
* 📱 **Responsive Design:** Culturally rich Bengali typography and warm terracotta UI tailored for all screens.

---

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Vite, Tailwind CSS, Lucide Icons
* **Backend & Database:** Supabase (Database & Authentication)
* **Deployment:** Vercel (CI/CD Pipeline)
